## Легенда символів

```
Булевські оператори:
a ──────> b         Тотожність (Identity)
a ──∨──> b          Заперечення (NOT)
a ⟍
b  ∨──> d          Диз'юнкція (OR)
c ⟋
a ⟍
b  ∧──> d          Кон'юнкція (AND)
c ⟋

Обмеження:
E ⋯⋯ a, b          Exclusive - a і b не можуть бути одночасно істинними
I ⋯⋯ a, b, c       Inclusive - хоча б одне має бути істинним
O ⋯⋯ a, b          One and only one - тільки одне має бути істинним
R ⋯⋯ a, b          Requires - якщо a, то b (і навпаки)
M ⋯⋯ a, b          Mask - якщо a, то NOT b
```

## Діаграма 1: Створення постачальника (POST /api/v1/suppliers/)

### Специфікація
- **Вхід:** name (обов'язкове), contact_info (опціональне)
- **Вихід:** 201 Created / 422 Validation Error / 400 Duplicate

### Причини та наслідки

```
Причини (Inputs):
┌─────────────────────────────┐
│ 1. name надано (не порожнє) │
│ 2. name унікальне (не існує)│
└─────────────────────────────┘

Наслідки (Outputs):
┌──────────────────────────────────────┐
│ 20. Постачальник створено (201)      │
│ 21. Помилка: name обов'язкове (422)  │
│ 22. Помилка: дублікат name (400)     │
└──────────────────────────────────────┘
```

### Функціональна діаграма

```
Inputs                    Intermediate            Outputs
                           Nodes

    ┌───────────┐
    │ 1. name   │⟍
    │  надано   │ ⟩────∧────> ┌────────┐ ────────> ┌────────────┐
    └───────────┘            │10. OK  │            │20. Success │
                             └────────┘            │   (201)    │
    ┌───────────┐⟋                                 └────────────┘
    │ 2. name   │
    │ унікальне │
    └───────────┘


    ┌───────────┐
    │ 1. name   │──∨──> ┌──────────┐ ────────────> ┌────────────┐
    │  надано   │       │11. Empty │                │21. Error   │
    └───────────┘       └──────────┘                │   422      │
                                                     └────────────┘


    ┌───────────┐
    │ 2. name   │──∨──> ┌────────────┐ ──────────> ┌────────────┐
    │ унікальне │       │12. Duplicate│             │22. Error   │
    └───────────┘       └────────────┘             │   400      │
                                                     └────────────┘

Обмеження:
    E ⋯⋯ 20, 21, 22  (тільки один результат може бути істинним)
```
